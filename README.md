# Sightline releases

Installers for Sightline, a standalone League of Legends companion app for Windows.

Download the latest `Sightline_x.y.z_x64-setup.exe` from [Releases](https://github.com/Boic69/sightline-releases/releases/latest). Once installed, Sightline checks this page for new versions and offers to update itself.

This repository only holds installers and the update manifest (`latest.json`). Every installer is signed, and Sightline refuses updates that aren't.
